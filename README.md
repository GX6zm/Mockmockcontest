# OI 模拟赛 · 校赛版

一个把**中国 OI 赛制**搬进浏览器的比赛模拟器：赛中没有任何评测反馈，榜上是每位选手的**自我估分**，比赛结束后统一出分——然后你会看到挂分、反挂分和名次大洗牌。

## 名单与成长

- 选手名单来自**校 OJ 排行榜**（Hydro，`oj.gxyzh.com`），只保留 **LV2 及以上**，删掉管理员账号和重复账号后共 **54 人**，存在 `src/roster.ts`
- 实力换算：按 **RP 70% + AC 30%** 的组内百分位，其中 **35 人（覆盖率 65%）**再用 CSP-J/S 正赛成绩修正
  - 有成绩的人：`0.6 × 校 OJ 百分位 + 0.4 × 正赛水平`
  - 没有成绩的人：保持校 OJ 单一来源，不参与混合
- **默认全员参赛**（54 人），人数滑杆可以只抽一部分
- 每场比赛后结算 **rating**（Elo 思路，零和）：爆冷的名次涨得多，热门翻车跌得多；同时累计参赛场次、冠军数、AK 数
- 成长数据存在浏览器 `localStorage`，关掉再打开还在；换电脑/换浏览器需要重新累积

## 正赛成绩：OIerDb + CSP 获奖名单

校 OJ 的 RP 在很大程度上只反映**做题量**，而且不是所有人都在校 OJ 上做题，所以正赛成绩是主依据、校 OJ 只作参考。两份数据都并进来了：

| 来源 | 覆盖 | 依据 | 权重口径 |
|---|---|---|---|
| **OIerDb**（`oier.baoshuo.dev/school/3319`） | 校内 30 人，其中 **21 人在校 OJ 名单里** | 历年所有正赛折算的**全国排名 + 评分** | 评分按 log 尺度 → 0.70–0.99（2000 分→0.70，32000 分→0.99） |
| **CSP-J/S 2023–2024 陕西** | **中 15 人**（且没有 OIerDb 记录的） | 全国名次曲线（无则退回同奖项内分数） | 提高一等约 0.78–0.90；入门组整体再减 0.15 |

最终每个人：`0.2 × 校 OJ 百分位 + 0.8 × 正赛水平`；**没有正赛记录的人仍按原来的校 OJ 算法**（RP 70% + AC 30% 的百分位）。共 **37 人**有正赛数据（69%）。

为什么 OIerDb 的下限是 0.80：能进 OIerDb 说明至少拿过省一，本来就强于「CSP 提高二等（0.80）」这条线，所以它的取值区间压在 0.80–1.00。

## 玩法

1. 选赛事模板（校赛 / CSP-J / CSP-S / NOIP / NOI），调人数、时长、每题难度（洛谷颜色）、随机种子
2. 看比赛：选手会先通读题面、按顺序开题、读题、思考、写暴力、对拍、犹豫要不要交、最后十分钟回去抢救
3. 赛后：统一评测 → 估分榜 → 逐个揭晓真实成绩 → 最终排名 + 战报 + rating 涨跌

## 赛制（B 档：校赛 OI）

- 全程**无评测反馈**，提交只是存了一版代码
- 每题 4 个子任务：**10 / 20 / 30 / 40** 分
- 以**最后一次提交**为准，赛后统一出分
- 选手可能挂分（估的高、实得低），也可能反挂（低估了自己）

### 知识点和颜色是绑死的

题库里每条标题都带「适用档位」，出题时只在该档的池子里抽，所以不会再出现「红题是后缀数组」「黑题是排队打水」：

| 档位 | 会抽到的题（举例） |
|---|---|
| 红 / 橙 | 排队打水、日期计算、最大公约数、爬楼梯、前缀和、图的遍历 |
| 黄 | 0/1 背包、单源最短路、并查集应用、字符串哈希、多边形面积 |
| 绿 / 青 | 线段树、树形 DP、强连通分量、凸包、KMP |
| 蓝 / 紫 | 网络流建模、平衡树、后缀数组、莫比乌斯反演、旋转卡壳 |
| 黑 | LCT、动态 DP、多项式 exp、广义 SAM |

### 高手做水题是真的"秒"

新手和高手的差别不只是通过率，还有**速度**。引擎里有「熟悉度」一项：`(选手该知识点实力 − 题目思考难度 − 15) / 45`，越熟悉压得越狠——读题、思考、编码、对拍、犹豫五个阶段分别最多压缩 50%/85%/70%/85%/60%，写挂的概率也同步下降。

实测（3 题全红、54 人、3 小时）：

| 选手 | 实力 | 首个红题 AC 用时 |
|---|---|---|
| 丁一宸 | 0.966 | 7.7 分 |
| 傻白虎 | 0.948 | 6.7 分 |
| 特别之处 | 0.946 | 6.5 分 |
| 周逸然 | 0.890 | 8.6 分 |

都在 10 分钟以内，符合「提高组一等过红题只要十分钟」的直觉。整套题越简单，开场通读也越短（全是红题没人会读满五分钟）。

## 选手在模仿哪些真实行为

不是凭空编的，这些都来自洛谷的 CSP 游记：

- **开场通读**：先花 4–10 分钟把整套题翻一遍，再决定顺序（几乎每篇游记的第一句都是这个）
- **顺序开题**：先做能稳拿分的，而不是一上来磕最难的
- **暴力保底**：想不出正解就写暴力/骗特殊性质，先锁 30 分
- **对拍**：拍出 bug 就回去返工——这也是最大的时间黑洞
- **手滑**：数组开小 `RE`、多测没清空 `WA`、常数被卡 `TLE`、精度写挂，以及最后 15 分钟慌慌张张**忘写 freopen**
- **心态**：卡题太久会去厕所冷静，回来重新规划

## 挂分是怎么来的

正赛发了大样例，选手拿样例自测完，基本就知道自己哪些子任务过了 —— 所以**估分就是「干净分」**，只带一点性格偏差（焦虑型低估、爆发型高估，偏差均值已减掉，保证整体不偏）和自我认知噪声。行情不对时他也会怀疑自己，去补交暴力保底。

暗病只有赛后才知道。挂分按**梯子**往外掏，幅度越大、越少见：

| 挂法 | 掉分 | 占挂分事件 |
| --- | --- | --- |
| `WA` 精度写挂 / 边界没处理好 | 最小的一个点（-10 为主） | 70% |
| `WA` 多测没清空 / `TLE` 常数被卡 | 最大的一个点 | 20% |
| 两个大点一起挂 | -50 ~ -70 | 7% |
| 整题爆零：`RE` 数组开小 / `CE` freopen 写错 | 整题（-100 只在满分子任务时） | 3% |

写挂概率随题目细节、难度、调试能力浮动；对拍过、返工过的代码明显更稳；暴力比正解好写。所以"挂分"不是随机惩罚，而是他**没对拍**、**想歪了**、**常数大**的账单——赛后战报会写清楚。

实测 24 场 × 54 人（校赛 3 题·3 小时·黄/绿/青）：**平均挂分 −12.2**、估得准（|差|≤20）**84%**、挂分≥41 的 6.9%、**反挂≥41 的 0%（最大 +40）**、估≥60 却真 0 分 0.1%、AK 1.2%。挂分幅度严格递减：0–10 分 24.9% → 11–20 分 12.2% → 21–30 分 4.6% → 31–40 分 4.3% → 41–60 分 3.3% → 61–80 分 2.4% → 81–100 分 0.8% → 100+ 0.5%。

**操作流程**

1. 选模板、拉人数/时长/难度滑杆，点「🚀 开始比赛」
2. 看榜单涨落：`≈` 开头的是估分，右上角小数字是这题交了几次；右侧只有「谁在第几分钟交了第几次」
3. 右上角可以 `⏸ 暂停`、切 `1x / 2x / 4x`（只影响观看快慢，不影响结果）
4. 想跳过漫长的等待：`⏩ +10 分` 一次推进 10 分钟，`⏭ 到收卷` 直接跑完——走的是同一套固定步长，结果和自然播完**完全一致**
5. 比赛结束自动进入「统一评测中」→ 估分榜 → 点「🔓 公布真实成绩」逐条揭晓
6. 最后看最终排名、涨跌、Rating 变化、挂分榜、反挂榜、估分校准榜和战报；可以「同配置再来一局」或「换个配置」

**正赛虚构外校选手，按「分数池 + 官方名额/分数线」排名发奖**：每个赛事用官方公布的名额和分数线反推一整条分数分布（`src/field.ts`），外校选手按分位等距取样，因此「线 = 第 N 名」严格成立；省排名 = 池子里比自己高的人数 + 1，同分会并列。结算页同时给真实分、估分、挂分、省排名和奖项。

- 省一/省二/省三按官方线判：考到线就有奖，考得好的人多、省一就发得多（同一分数并列）。
- CSP 复赛 2025 陕西（官方）：785 人、一等线 100 分 / 157 人、二等线 30 分，不设三等。
- NOIP 2025 陕西：一等 128 分 / 32 人、二等 95 / 37 人、三等 86 / 10 人（全国获奖率 67%）。
- NOI 2025（满分 705）：金 50 / 银 152 / 铜 85，全国正式选手 338；铜牌还要求 ≥100 分；奖牌按全国名次名额发，不按线。
- APIO 2025 中国区（满分 300）：金 64 / 银 128 / 铜 193（线 193/130/80），按名次名额发牌。
- 省选：陕西 8 个名额（A5+B3），单校 ≤1/3 → 我校最多 2 人；总分 = NOIP 标准分×30% + 省选标准分×70%（标准分 = 本人 ÷ 全省最高 × 100）。
- 所有正式比赛晋级即自动报名，不能弃赛；带多少人也不设上限（成长按人数稀释：6 人满额，按 0.6 次方衰减，越多人越顾不过来）。

**初中 + 高中，六年年级**：每个学生有真实年级（初一 ~ 高三）。全校一张 S 卷、**初中生也能正常参加 CSP-S**（只要过初赛），但 NOIP 起正式名额只给高中生，初中生只有"后备体验 / 夏令营"（成绩证明，不授证书、不计奖）。J 组已按用户要求整体移除。每学年结束全部升一级：初三升高一、高三毕业离队，同时补 **6 个初一 + 4 个高一** 新生。`?years=1` 可以只打一届。

**比赛和观战模式是同一套引擎**：点「开考」后实时榜单、估分、暂停 / 1x·2x·4x / +10 分钟 / 到收卷全都有，也可以「跳过观看直接出成绩」。收卷先出估分榜，点「🔓 公布真实成绩」才把省排名、奖项、成长和疲劳写回去；同一 seed 下观看回放与瞬时结算逐分一致（`scripts/trace-check.mjs` 每场校验）。初赛是笔试，直接出分不套比赛引擎。

**得分率校准**：引擎算的是「这道题能拿多少原始分」，和真实考场的绝对分数不是一个刻度（原始分里紫题只有三成）。每场正式赛按官方分数线 / 历年真题得分率给一条分段线性曲线（`StageDef.curve`），把原始分映射到真实分——比如 CSP-S 强选手落在 84%（336/400）、NOIP 一等线附近 128、NOI 强选手 75% 上下。曲线只作用于正赛，观战模式不受影响。

**选手详情**：队伍状态里点任意名字展开（`src/StudentDetail.tsx`）：综合 / 心态 / 疲劳三个大数字，八个知识点各一条进度条，外加代码、阅读、调试、自我认知、抗压、耐心、冒险七个迷你数值。

**每周还是一个决定**：全队练哪个专题（8 选 1）+ 强度（常规 / 加练 / 休息）。约 62% 的周会撞上一个插曲（早恋、班主任、校领导、家长焦虑……），选完才能排训练，结果在周赛结算页回放。比赛周也照常训练（只是当周不打模拟赛）。没比赛的周打一场校内模拟赛，题数（2–4）、时长（2–4h）、难度档（基础 / 提高 / 冲刺 = 普及- ~ 普及 / 普及+ ~ 提高+ / 提高+ ~ 省选-）都能调——**难度比队伍水平略高一点时成长最多**。正式赛打完，参赛者按「题目难度 vs 自己水平」涨实力，同时累疲劳（一场 +8，两试 +16）。训练只说「练透了 / 稳步在涨 / 原地踏步」，真实涨幅藏在噪声里；疲劳一路带进比赛（`skill × (1 − 0.18 × 疲劳^1.3)`）。

**生涯评分**：按「每年平均产出」算（否则方差全压在几次省队上）：10 + 1.5×每年初赛过线 + 3×每年 S 省一 + 1.2×每年复赛省二 + 3×每年 NOIP 省一 + 8×累计省队 + 25/12/5×NOI 金/银/铜 + 4/1.5×WC·APIO 金/银 + 0.8×clamp(平均实力提升, 0, 30)。等级：S 85 / A 55 / B 34 / C 19 / D 0（2026-10 M6 校准，seed 20261019：三年生涯评分 20–91，强队 91 S、中队 36 B、弱队 20 C；强-弱差 71。评分只数「省一 / 省队 / NOI 奖牌」这类硬产出，弱队三年零省一就是 20 分上下）。

**年级数据**：`data/年级对照表.txt` 里填 54 个人的真实年级（把第二列的 `?` 改成 初一/初二/初三/高一/高二/高三，存 UTF-8，跑 `node scripts/grades.mjs`，再 `pnpm build:single`）。不填也能玩，模拟器按种子自动分配六个年级（初中约 46%、高中约 54%，每级至少 4 人）。

**天赋数据**：`data/天赋对照表.txt` 里手填每个人的**天赋**（0.85 慢 ~ 1.15 快，训练成长乘数，不直接改比赛得分）和**性格**（全能型 / 数学天才 / DP 大师 / 图论专家 / 暴力选手 / 稳定型 / 爆发型 / 焦虑型 / 贪心选手 / 实现之王）。改完跑 `node scripts/talent.mjs` 生成 `src/talent.ts`，再 build。天赋留空 = 沿用种子随机；性格留空 = 沿用种子抽签。备注列自动带上了 OIerDb 全国排名 / CSP 奖项，方便对着真实成绩定天赋。**选手全属性可手填**：`data/属性对照表.txt`（Tab 分隔，54 行）里有姓名、年级、性格、天赋、实力、8 个知识点、7 个元能力，属性写 0–100、留空沿用引擎值；改完跑 `node scripts/profile.mjs` 生成 `src/profile.ts`（`--check` 只校验，`--init` 重新生成模板并保留你填的格子）。选手详情卡里点开就是全部属性：综合 / 实力 / 心态 / 疲劳、八个知识点、七个元能力（代码/阅读/调试/自我认知/抗压/耐心/冒险）、天赋与性格、入学年份、开学综合与排名，以及本赛季已打过的每一场比赛成绩。

## 可复现

所有随机都走种子 RNG，并且**固定 0.5 秒步长**推进（零头留到下一帧），所以同一个种子 + 同一套配置，无论 1x / 4x、什么刷新率，结果完全一致。
