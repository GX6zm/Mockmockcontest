# OI 模拟赛 · 校赛版

一个把**中国 OI 赛制**与**中学信息学竞赛校队经营**搬进浏览器的比赛模拟器：覆盖从 **CSP 初赛 → 复赛 → NOIP → CTT → WC → CTS → 省选 → APIO → NOI → IOI** 的完整真实赛历，支持 **OI 盲测赛制**与 **IOI 实时评测赛制**、实时赛场直播与思维链复盘、多年校队养成与荣誉档案系统。

> **开箱即玩**：直接双击根目录的 [`OI模拟赛.html`](./OI模拟赛.html)（单文件离线版，已内置自定义开局 OP 编辑器与满血/静帧动效切换），无需联网或安装环境。

## 核心特色总览

### 1. 教练模式：真实 40 周 OI 赛历与双赛制引擎

一学年 **40 周**（9 月 → 次年 8 月），完整还原 **10 场正式赛事** 与跨学年国家集训队选拔周期：

| 周次 | 赛事 | 赛制 | 规格与时长 | 规模参考 | 晋级资格与说明 |
|---|---|---|---|---|---|
| W4 | **CSP 第一轮（初赛）** | 笔试 | 100 分 · 2h | 全国约 3.44 万 | 全校一张 S 卷（初中生同考），陕西基准线 37 分 |
| W8 | **CSP 第二轮（复赛）** | **OI** | 4 题 · 4h（满分 400） | 陕西 S 785 人 | 初赛过线；S 组二等及以上进 NOIP |
| W12 | **NOIP** | **OI** | 4 题 · 4.5h（满分 400） | 全国约 7,725 人 | CSP-S 二等及以上（限高中生；初中生为后备体验） |
| W14 | **CTT 国家集训队集训** | **IOI** | 3 题 · 5h × 3 试 | 国集 50 人 | **跨学年结转**：上学年 NOI 前 50 参赛，前 30 进 CTS |
| W18 | **WC 冬令营** | **IOI** | 3 题 · 5h（满分 300） | 约 500 人 | NOIP 一等（省推荐），按全国名次评金/银/铜牌 |
| W19 | **CTS 国家队选拔** | **IOI** | 3 题 · 5h × 2 试 | 约 30 人 | 与 WC 同期；CTT 前 30 参赛，前 6 答辩定 4 人国家队 |
| W23 | **省选（两试）** | **OI** | 3 题 · 4.5h × 2 试 | 陕西 160 人 | 总分 = NOIP 30% + 省选 70%；陕西 17 省队（A5+B12，单校 ≤5）；初中达线获 NOI E 类资格 |
| W28 | **APIO** | **IOI** | 3 题 · 5h（满分 300） | 中国区约 640 人 | 省队或 NOIP 一等高中生，按全国名次评金/银/铜牌 |
| W34 | **NOI（笔试 + 两试）** | **OI** | 笔试 100 + 两试 600 + A 类 5 | 正式约 338 人 | 满分 705；金 50 / 银 152 / 铜 85；前 50 进下学年国集并获保送资格 |
| W39 | **IOI 国际赛** | **IOI** | 3 题 · 5h × 2 试（满分 600） | 全球约 353 人 | 本学年 CTS 前 4 名出征，按全球 1/12 金、1/4 银、1/2 铜发牌 |

- **双赛制差异**（`format: 'oi' | 'ioi'`）：
  - **OI 赛制**：全程无评测反馈，榜上只显示自估分，以最后一次提交为准，赛后统一出分并结算挂分/反挂分。
  - **IOI 赛制**：赛中实时评测返回真实分数，取历次提交最高分，无 `freopen` 爆零；评测出锅后选手会自动进入 `fixing` 阶段紧急修 bug 重交。
- **动态历年卷面与浮动分数线**（`PAPER_HISTORY` + `stagePaperForYear`）：每场正赛以近年真题难度中位数为锚、在历史合理区间内生成当年试卷，省线/分数线随整卷难易自动浮动（`paperShift`）。
- **国集积分制**：总成绩 = 作业/互测 `10%` + CTT 三场各 `18%`（`54%`）+ CTS 两场各 `18%`（`36%`）；CTS 前 6 进入论文答辩（作业 40% + 上学年 NOI 25% + 阅读表达 20% + CTS 15%），定 4 人国家队。
- **赛前战术指令**（`ContestTactic`）：正赛开考前可下达**稳健保底**、**常规**或**搏命冲高**指令。

### 2. 三大挑战剧本 & 学年目标契约

开档时可任选剧本与学年目标，决定校队资源与考核压力：

| 剧本 | 标签 | 初始资源与规则 |
|---|---|---|
| **标准校队** | 默认 · 不限学年 | 声望 50 开局，传承正常校队梯度，自由执教多年打造百年强校 |
| **荒漠重建** | 高难挑战 · 5 年重建 | 声望 20 · 经费 25 · 停课 1 周 · 全员从零起步，5 年极限冲省队 |
| **背水一战** | 单季冲刺 · 1 年限时 | 仅有 1 学年窗口！声望 65 · 经费 90 · 停课 5 周，一季定胜负 |

每学年初签署**学年目标契约**（完成得经费/停课额度/声望奖励，未达标扣声望）：
- **稳健保底**：本学年省一（CSP-S / NOIP）≥ 2 人（成：经费 +10、声望 +2；败：声望 −3）
- **进取争先**：本学年省队 ≥ 1 人或省一 ≥ 4 人（成：经费 +18、停课 +1 周、声望 +4；败：声望 −5）
- **豪赌冲金**：本学年 NOI 奖牌 ≥ 1 块或省队 ≥ 3 人（成：经费 +30、停课 +2 周、声望 +7；败：声望 −8）

### 3. 深度周常经营：资源、特训、个别关照与一键快进

- **主力 + 梯队双线培养**：主力至少 6 人（上不封顶，成长随人数稀释），梯队最多 12 人；支持给梯队指定**独立专题**，并选择教练精力分配（主力优先 / 均衡 / 梯队优先）。
- **四大战略特训项目**（每周最多启用 1 项）：
  - **申请停课集训**（消耗停课 1 周）：全队成长 ×1.45、作业 +3，额外疲劳 +10，下周文化课压力事件概率翻倍。
  - **外校联训营**（经费 25，每学年限 3 次）：主专题成长 ×1.65（120 以上超频衰减减缓）+ 顺手补弱项，额外疲劳 +14。
  - **请往届学长讲课**（经费 15）：邀请已毕业强手返校讲授其最强专题，定向补专题 + 提调试阅读 + 全队疲劳 −4。
  - **赛前防挂题包**（经费 12）：显著提升全队代码/调试能力、压低写挂率、作业 +4。
- **个别关照**（每周最多指定 2 人）：`单人轮休`（大幅回疲劳）、`专项补短`（改练自身最弱专题效率 ×1.35）、`代码调试`（强化编码/调试/阅读）。
- **一键快进训练周**：支持沿用当前周计划自动快进多个训练周，撞上事件插曲或正赛周自动停下。
- **37 个校园事件（含 6 条多周连续剧）**：覆盖感情、教学、行政、家庭、机会、健康、竞争、梯队、后勤、跨界、氛围等标签，包含挖角风波再起、班主任与家长三方约谈、领跑后松懈→重燃斗志、双人互测搭档验收、毕业校友赠评测机→校友杯开赛、手腕腱鞘发炎→复查结果等多周剧情链，以及半夜打 CF、互卡常 Hack、撞原题风波、空调罢工、校长突击巡视等机房日常。

## 名单与正赛数据口径

- 选手名单来自**校 OJ 排行榜**（Hydro，`oj.gxyzh.com`），保留 LV2 及以上、去除管理员与重复账号后共 **54 人**，存放在 `src/roster.ts`。
- 结合 **OIerDb**（`oier.baoshuo.dev/school/3319`）与 **CSP-J/S 2023–2024 陕西获奖名单**校准初始水平（共 37 人有正赛数据，覆盖率 69%）：

| 来源 | 覆盖 | 依据 | 权重口径 |
|---|---|---|---|
| **OIerDb** | 校内 30 人，其中 21 人在校 OJ 名单 | 历年正赛折算的全国排名 + 评分 | 评分按 log 尺度映射至 0.70–0.99 |
| **CSP-J/S 2023–2024 陕西** | 15 人（无 OIerDb 记录） | 全国名次曲线（无则退回同奖项内分数） | 提高一等约 0.78–0.90；入门组再减 0.15 |

有正赛记录者按 `0.2 × 校 OJ 百分位 + 0.8 × 正赛水平` 计算，无记录者保持校 OJ 单一来源（RP 70% + AC 30%）。

### 数据表与自定义脚本

- **年级数据**：编辑 `data/年级对照表.txt` → 跑 `node scripts/grades.mjs` 生成 `src/grades.ts`。

## 题目难度与真实考场机制

### 洛谷 8 档颜色难度

| 档位 | 颜色 | 典型定位 | 示例题型 |
|---|---|---|---|
| 入门 | 红 | CSP-J T1 | 排队打水、日期计算、最大公约数 |
| 普及- | 橙 | CSP-J T2 | 爬楼梯、前缀和、图的遍历 |
| 普及 | 黄 | CSP-J T3 / CSP-S T1 | 0/1 背包、单源最短路、并查集、字符串哈希 |
| 普及+/提高- | 绿 | CSP-S 一等线 | 线段树、树形 DP、强连通分量、KMP |
| 提高 | 青 | CSP-S 强省一等 | 凸包、进阶 DP 与数据结构 |
| 提高+/省选- | 蓝 | NOIP 强省一等 | 网络流建模、平衡树、后缀数组 |
| 省选/NOI- | 紫 | 省队门槛 | 莫比乌斯反演、旋转卡壳 |
| NOI/NOI+/CTS | 黑 | NOI 金牌 | LCT、动态 DP、多项式 exp、广义 SAM |

### 考场行为与挂分梯子

- **真实行为链路**：开场通读（4–10 分钟）→ 按能稳拿分顺序开题 → 读题/思考/编码/暴力保底 → 对拍（拍出 bug 返工）→ 犹豫交卷 / IOI 实时评测修锅 → 收卷前检查文件。
- **熟悉度加速**：高手面对远低于自身水平的题目，五个阶段耗时最高压缩 50%–85%，且写挂率显著下降。
- **OI 赛制挂分梯子**（对拍过/调试高可大幅压低触发率）：
  - `WA` 精度/边界写挂（掉最小点 -10 为主）：70%
  - `WA` 多测未清空 / `TLE` 常数被卡（掉最大点）：20%
  - 两个大点一起挂（-50 ~ -70）：7%
  - 整题爆零（`RE` 数组开小 / `CE` 忘写 `freopen`）：3%
- **成长与疲劳口径**：8 个专题上限 **150**（名单顶尖约 120，周康阳级 IOI AKer 约 145）；疲劳仅减缓训练效率（100 疲劳 ≈ 效率 ×0.45），不直接扣比赛实力。
- **生涯评分**：按年均产出（分母至少 3 年）+ 生涯高光（封顶 15）定级（S 85 / A 55 / B 34 / C 19 / D 0）。

## 本地开发与构建

```bash
npm install
npm run dev          # 开发服务器：http://localhost:3000
npm run typecheck    # TypeScript 类型检查
npm run build        # 构建到 dist/
npm run build:single # 构建并打包单文件 OI模拟赛.html + 同步 site/index.html
```

生成独立 OPv 满血 / 静帧版本：

```powershell
# PowerShell
$env:OPV="1"; npx vite build
node scripts/inline-opv.mjs
```

如需构建默认静帧版 `dist/`，设置 `MOTION=0` 即可。

### 自动化验证脚本

```bash
node scripts/trace-check.mjs        # 校验比赛直播回放与瞬时结算逐人逐分一致
node scripts/career-check.mjs       # 校验多年生涯、年级递进、毕业/新生与结算一致性
node scripts/event-check.mjs        # 校验事件系统可复现性与状态边界
node scripts/balance-check.mjs      # 成长速率与训练强度探针
node scripts/peak-check.mjs         # 高天花板选手 NOI→CTT→CTS→答辩→IOI 全链探针
npm run check:profile               # 校验属性表
```

校验日志自动记录在 `logs/verify.log`。所有模拟均基于种子 RNG + 固定 0.5 秒步长，保证同配置同种子完全可复现。
